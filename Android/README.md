# 音频播放器

应用名「音频播放器」，包名 `com.nanahoshi.audioplayer`。

这是一个 Android 音频播放器，支持本机文件、B 站音轨、YouTube 独立音轨、[asmr.one](https://asmr.one/) 作品和 DLsite 已购内容；可以生成日文字幕、翻译成中文，也能把在线内容下载到手机离线播放。

## 快速开始

1. **安装**：Android 7.0（API 24）及以上。到 [Releases](https://github.com/nanahoshi114/AudioPlayer/releases) 下载最新的 Android APK 安装，Android 发布标签以 `android-` 开头。想自行编译，见文末[编译](#编译)。
2. **导入内容**：在音频库点右下角「导入」，可以导入本机文件或文件夹，或点「导入在线音频」跳转在线搜索。作品用 RJ 号或关键词查找；B 站支持视频关键词、BV 号及 UP 主；YouTube 支持关键词和视频／列表链接。DLsite 已购内容需要先在「我的」登录，再从「查看已购买作品」打开。YouTube 在「在线搜索 → YouTube」查找，可在线播放、加入在线曲目或下载后自动加入音频库。
3. **配置字幕（可选）**：打开「设置 → 听写和翻译」，选择听写模型并保存（选 `SenseVoiceSmall` 时改为下载本机模型）；需要翻译时，在同一页选择翻译平台并填写 API Key。播放时如果没有现成字幕，可以点「生成字幕」或「生成字幕和翻译」。`Qwen3-ASR` 的地址在局域网、本机或 `.local` 时，首次访问需要允许本地网络。
4. **下载（可选）**：在单首「更多」、多选「下载」、作品详情、收藏夹或正在播放页发起下载。有进行中的下载、听写或翻译时，右上角下载图标会显示数量；完成后到「设置 → 下载管理」查看。

## 界面

打开应用后，底部有五个分页：音频库、播放列表、在线搜索、我的、设置。五页顶部都有标题栏，右上角是下载入口；有进行中的任务时图标上显示数量。底部正在播放的小条是一张圆角卡片，卡片底边显示播放进度。

作品详情、音频库里的作品页、已购买列表、收藏夹、正在播放、下载与任务、下载管理、听写和翻译、清理缓存、文件预览是单独页面。作品页和作品详情会留下底部五个菜单和播放条，只把顶部标题栏滑走。其余页面离开五个主页面时，顶栏和底栏都会滑出隐藏。

音频库和在线搜索页的搜索、筛选栏，向上滑动页面时收起，向下滑动时重新出现；松手时如果没收起一半，会弹回完全展开。音频库的排序在搜索栏旁的图标里，和搜索栏一起收起。导入按钮在右下角，列表向下滚动时收成圆形。多选时，顶栏换成已选数量和操作。

## 音频库

音频库按文件夹逐层展开。本机文件、B 站音轨和在线作品可以混放在同一层。

### 导入内容

点右下角「导入」，可以选择：

- 选择文件导入
- 选择文件夹导入，保留原来的目录结构
- 导入在线音频，跳转到在线搜索，恢复上次选择的来源和页面状态

在线搜索加入音频库的内容统一放在音频库根目录，不使用发起导入时所在的文件夹。

### 剪贴板导入

首次进入应用或从后台返回时，应用在后台识别剪贴板。明确的 B 站和 YouTube 视频链接优先，其次匹配带 `RJ` 的作品编号，也支持独立 BV 号。查到标题和封面后弹出预览。没有明确编号或链接时，连续六位数字或以 `01` 开头的连续八位数字会触发底部提示，点「查找作品」后才查询。关闭提示或等待它消失后，这次复制的内容会记为已处理。

RJ 编号保留原有前导零，不足六位的带前缀简写补足六位。应用先查音频库，再查 asmr.one。asmr.one 未收录时会查 DLsite 并核对已购记录。已购作品可确认导入 Play 文件，未购作品显示「没有有效来源，无法加入音频库」，可点「查看详情页」。主动点「查找作品」后，两边都查不到时会在底部提示「没有找到这部作品」。连接失败时会提示检查网络。

单 P 的 B 站视频确认按钮显示「导入」，多 P 视频显示「选择导入方式」。确认后才放入音频库根目录，不自动播放或下载。B 站多 P 在下一步选择「分开导入 / 统一导入」，分开导入时可勾选且默认全选，统一导入包含整视频全部 P。YouTube 会加入在线曲目。已加入音频库的 B 站视频仍可确认后调整导入方式，原曲目编号不变。

同一份剪贴板处理后不会反复提示；Android 8 及以上重新复制相同内容后可再次提示。应用只在前台取得焦点后读取，不清空剪贴板；只保存用于去重的摘要，不保存剪贴板原文。仅播放列表的 YouTube 链接不自动批量导入。

### 浏览与筛选

搜索栏旁的排序图标可以在名称和加入时间之间切换。音频库根目录可在「全部 / B 站 / YouTube / asmr.one / 本地」之间筛选。进入普通文件夹后隐藏来源筛选，搜索仅在当前目录及子目录中进行，不受根目录来源选择限制，也不弹出在线 RJ 导入提示；清空搜索恢复当前目录，回到根目录恢复原来的筛选。路径栏在搜索时也保留，排序按钮移到搜索栏右侧。

- 「B 站」显示独立 B 站音轨和统一导入的视频项，视频项带「多 P」标签，不重复列出其中各 P。多 P 视频的列表和详情页使用与普通音轨相同的「B 站」来源标签配色。
- 「YouTube」只显示已加入音频库或已下载的 YouTube 曲目，不显示文件夹。
- 「asmr.one」只显示带作品编号的在线作品文件夹，包括从 DLsite 加入音频库的作品，不展开里面的单首。
- 「本地」按文件夹浏览，隐藏在线作品文件夹，文件夹内只显示本机音频。如果当前位于在线作品文件夹内，会先退到最近的普通文件夹。
- 搜索会匹配文件夹名、作品标签、曲目名和文件名；搜索纯数字时，还会匹配作品编号。作品内部的子文件夹、曲目和文件会归到作品，一个作品只出现一次。
- 根目录保持原有搜索与筛选规则，目录内搜索仅返回当前目录及其后代。多 P 内部命中会归并为整视频项，归并结果不会越出目录范围。

### 作品页

点已加入音频库的在线作品会打开单独的作品页，音频库列表停在原来的位置。底部五个菜单和播放条保持显示。

页面上方是封面、标题、RJ 号、社团、声优、发售日，标签超过 8 个时可以展开。图库和试听不在这一页，在右上角「更多」里点「在线详情」打开。下面是「下载到本地」、「关联本地文件夹」和文件列表。路径从「根目录」开始，点击任一祖先目录会直接到达该层。路径太长时会自动露出当前目录，可以横向滑动查看前几层。左上角返回和系统返回都会先回到上一级，到作品根再退出页面。

作品页分两层滚动：作品信息、按钮和整个文件框先随页面滚动；文件框到顶部后，只有文件行滚动，「文件」标题、来源切换和面包屑保持不动。向下翻时，作品页没到底会先滚作品页，到底后才滚文件；在文件区向上翻时，先滚文件，文件到顶后再回到作品页。作品页里的文件夹和文件固定按名称排序，不受音频库的排序影响。进入子文件夹只把文件区回到开头。返回父目录时，文件读取完成后恢复原来的位置。文件预览返回和屏幕旋转后会保留浏览目录、来源和滚动位置。

作品同时有 DLsite 和 asmr.one 两套文件时，可以用「DLsite Play / asmr.one」切换。列表只显示当前这一套，点任意一首播放时，队列也只放入当前这一套的曲目。「下载到本地」时，如果已购买（读缓存，不联网查）而且 asmr.one 里也有这部作品，会先弹窗让你选来源。选择 DLsite 会下载完整原始包并自动解压，不再询问音频格式；即使在子文件夹发起，也下载整部作品。选择 asmr.one 时，同目录里只差扩展名的音频（如 xx.mp3 和 xx.wav）仍会先询问下载哪种格式，没有冲突的音频照常下载。作品里已经有 Play 文件时，打开后会直接显示切换，不会因为 DLsite 连不上而一直等。

原始包解压后，DLsite 文件区显示完整原始目录，保留各音频格式和附带文件。如果新版原始包移除了当前子目录，作品页和在线详情会回到最近仍可见的上级目录，等列表读取完成后恢复该层的滚动位置。能匹配的原有曲目保留编号、播放列表和字幕关联，原始包独有的音频会补充加入音频库。原始包保留作者上传的文件，音质以作者提供的文件为准，不保证每部作品都有无损音频。

空的已购作品会重新读取文件。读取时显示「正在读取文件…」；DLsite 和 asmr.one 都没有文件时，显示「没有找到这个作品的文件」。

作品内可以长按多选，但不能从音频库单独移除其中的音频、图片、文本、其它文件或子文件夹；其它页面也遵循这一规则。「删除已下载文件」仍然可用。右上角「更多」里的「从音频库移除」针对整部作品，确认后移除并回到音频库，磁盘文件及原始包清单仍保留。

### 多选与单条操作

长按任意一项进入多选，顶栏显示已选数量。接下来播放、加入播放队列、下载是图标；加入播放列表、删除已下载文件或取消本地关联、移除在「更多」里。只要选中了作品，接下来播放、加入播放队列、下载、加入播放列表就不显示，只保留下载副本、本地关联和移除相关操作；作品行「更多」里的「下载到本地」不受影响。选中的项会换行显示完整名称，未选中的项只显示一行。

点进子文件夹时从这一层开头显示；返回后，上一层仍停在原来的位置。每一层分别记录位置。从上一层再次进入同一个文件夹时，会从开头显示。

单条「更多」中，在线音频可以单独下载；带作品编号的文件夹可以「下载到本地」：已购买且 asmr.one 也有收录时先选来源，否则下载当前显示的那一套（在作品外面发起、没有弹窗时，有 Play 文件就下载 DLsite Play，否则 asmr.one）。

「删除已下载文件」用于删除应用保存的音频副本。「取消本地关联」仅解除在线曲目与手机原文件的关联，保留原文件和生成字幕。多选同时包含两类文件时，确认弹窗分别列出要删除的副本数和要解除关联的曲目数。待删除的下载副本带有生成字幕时，可选择是否一并删除。保留的字幕可在「设置 → 下载管理 → 字幕」里单独删除，重新下载同一音频也会自动匹配。

图片和文本可以预览，图片可以用双指缩放。不支持应用内预览的文件提供「使用其他应用打开」：已有本地文件直接打开，远端文件先自动暂存，显示进度并可取消，再交给外部应用。暂存属于可清理缓存，不会作为音频加入音频库；正在下载或当前预览页仍在使用的暂存受保护，退出预览页后纳入缓存清理。没有本地副本和单文件地址的原包独有文件需重新下载完整原始包。字幕文件不会单独列出，对应音频会标「有字幕」。

### 关联为作品

作品已经在音频库里时，作品页的「关联本地文件夹」可以选手机上的一个文件夹，对照当前显示的那一套文件，对上的曲目会挂上本地文件（显示「已下载」，播放读本地文件），曲目 id 不变，原文件不动。本地可以少，不能多出作品里没有的。同一个本地文件已经挂在别的曲目上时，这次会跳过并在提示里说明。

本地文件夹还不是作品时，可以在单条「更多」里选「关联为作品」，填写 RJ 号。应用会先检查 DLsite：如果已经购买、登录有效，并且能读取文件树，就先对照 DLsite 的文件；否则再对照 asmr.one。DLsite 登录失效时会提示重新登录，不会当作没购买。

- 本地文件可以少于作品内容，不能多出作品里没有的文件或文件夹。多出的内容会写在提示里。
- 对上 DLsite 时提示「DLsite匹配成功」，曲目标记为 DLsite；对上 asmr.one 时提示「asmr.one匹配成功」。
- DLsite 未连接、asmr.one 也对不上时，提示「DLsite未连接且asmr.one匹配失败」。两边都对不上时，提示「DLsite/asmr.one均匹配失败」。
- 匹配成功后，曲目编号和本地路径不变，已生成的字幕仍然保留。名称比较忽略全角、半角和大小写。

## 播放

应用支持后台播放，通知栏可以控制播放。正在播放页从上到下是封面、标题、字幕、进度和播放控制。播放键下方是定时关闭、队列；B 站音轨尚未下载时还有「下载音轨」。定时关闭倒计时中会显示剩余时间，时间到后自动停止并提示。

B 站视频属于合集时，播放页功能区显示「合集：合集名称」，点击直接打开所属合集详情，可以继续浏览或收藏。已加入音频库和未加入音频库的 B 站音轨都支持；读取不到有效合集信息时不显示入口，长名称最多显示两行。跳转不会停止播放或替换队列，返回回到播放页。

点「队列」会从底部打开当前播放队列，可以拖动排序、删除单首。清空和关闭在标题栏右侧，清空需要先确认。队列弹层不响应下滑关闭，避免和列表滚动、拖动排序冲突。队列里可以放入尚未加入音频库的在线音频，关闭应用后队列仍会保留。

B 站音轨尚未下载时，正在播放页会显示「下载音轨」。下载只保存音频，不保存视频；下载后播放会直接读取本地文件。视频自带字幕会一起保存到本地，之后离线播放也能显示。收藏夹中也可以对选中的视频执行「下载音轨」，没加入音频库的音轨在下载管理里播放时也能显示下载字幕。

## 字幕

已有字幕按来源读取：

- 本地文件：查找同一层目录中同名的字幕。
- asmr.one：查找同一文件夹中同名的文本。
- B 站：使用视频自带的字幕，也支持未加入音频库的队列项。B 站字幕需要有效的 B 站登录；未登录或登录失效时，播放页会提示先重新登录，不会把它当成视频没有字幕。下载音轨时会把字幕一起存到本地，已经下载过的曲目优先读本地字幕。
- DLsite 音轨没有现成字幕。

### 生成字幕

没有现成字幕时，可以在正在播放页选择「生成字幕」或「生成字幕和翻译」。

- 「生成字幕」只生成日文字幕，不请求翻译。
- 「生成字幕和翻译」在听写完成后继续翻译成中文。

手机中已有音频文件时直接使用。asmr.one、DLsite 和 B 站音轨尚未下载时，会先加入下载队列，文件到达后再听写。DLsite 已购音轨会先询问下载完整原始包还是所选音频；选择完整原始包后，听写等待下载、解压和目标音频关联完成，缺文件的手动重试也会询问。取消听写不会中止共享的音频下载。没有本地文件且无法下载的音频不能生成。听写和翻译接口在「设置 → 听写和翻译」中配置。

生成结果按文件内容保存。同一文件、同一听写地址、同一模型已经完成，并且字幕文件仍然存在时，不会重新生成；更换地址或模型会重新生成。退出正在播放页不会中断已经开始的翻译或润色。

点开字幕会从下方展开全文。当前句会高亮，点击任意一句会跳到该句开头，列表仍留在这一页；返回后回到正在播放页。正在播放页上的当前句也可以打开全文列表。全文默认跟随播放进度；手动滚动后会暂停跟随，点「回到当前句」恢复。

有中文译文时，全文顶部可以在「中文 / 日文」之间切换。切换到中文后，右上角可以点「润色」；没有译文时可以点「生成翻译」。所有来源的字幕在明确为简体中文时隐藏「生成翻译」；短句、简繁同形或混合语言等无法确定的情况仍保留入口。B 站继续自动选取字幕，不提供字幕语言选择。正在翻译或润色时，这个按钮变成「中止」。应用生成的字幕可以在「更多」里删除，之后可以重新生成。听写没有检测到人声时显示「没有听出人声」，也可以删除后重试。

### 桌面字幕

在「设置 → 字幕」打开「桌面字幕」，按系统提示允许「显示在其他应用上层」。音频继续播放时，切到桌面或其他应用即可看到当前句。字幕跟随播放页的中文／日文选择，回到播放器或锁屏时自动收起，在后台解锁后恢复显示。

长句会自动换行。字幕超过悬浮窗的可用高度时，会随当前句的播放进度向上滚动，锁定时也能看到后半段。

拖动字幕可以调整位置。轻点字幕展开上一首、播放／暂停、下一首、锁定和关闭。点暂停后控制条保留 30 秒，方便继续播放。锁定时触摸会传给下方应用，回「设置 → 字幕」关闭「锁定桌面字幕」即可解锁。

### 灵动岛字幕

真我 RMX5010（系统构建 `RMX5010_17.0.0.112(CN01)`）实测，调试版提供的测试文字和实际字幕均未在流体云胶囊中显示。应用使用系统媒体卡片显示曲名、封面和创作者。后台看字幕请使用「桌面字幕」。

## 播放列表

可以把常听的内容整理成普通播放列表。右下角「新建」用来建列表，列表里可以改名、删除，也可以拖动调整曲目顺序。详情页的「播放」会替换当前播放队列，「加入播放队列」会追加到当前队列；列表里没有「加入音频」按钮，只能在音频库里多选音频后加入播放列表。

普通播放列表的卡片按曲目顺序展示最多三个不同作品的封面。同一作品的多首曲目只占一个位置，包括 asmr.one 和 DLsite 中已归到同一作品的音轨。B 站按视频区分，同一视频的不同分 P 共用一个位置，不同视频即使使用相同图片也各占一个位置。没有作品归属的本地曲目按单首区分。

播放列表也可以收藏 B 站 UP 主的合集和系列，卡片标明「B 站合集 / B 站系列」及视频数量。合集和系列统一使用第一个视频的封面，不使用合集自身封面；首视频没有封面时显示默认图标。收藏只记录合集入口，不自动将视频加入音频库，也不下载音频；此收藏仅保存在本 App，不等同于订阅到 B 站账号。

打开在线列表时先显示上次完整读取的目录，再刷新远端内容；可手动刷新或中止。条数与总数不一致时会自动重读一次；仍不一致时显示已读到的视频并提示目录可能不完整，已记录的完整目录不会被覆盖，也不会把一页内容当作完整合集。UP 主新增视频、移除视频或调整顺序后，成功刷新会更新在线列表；已加入音频库的曲目、文件和当前播放队列不会随之删除或重排。

在线列表支持正序、倒序和随机排序，默认按远端目录正序显示；随机顺序在当前页面内保持稳定，再次选择「随机」可重新打乱。排序同时用于显示、播放、追加及批量操作，多 P 视频内部始终按 P 序号展开；排序不改变已在播放的队列，也不改变合集封面所用的远端首视频。

在线列表可「按当前排序播放全部」「加入播放队列」、选中部分视频播放、加入音频库或下载。进入多选后隐藏顶部这两个整合集按钮，使用多选栏处理已选视频；取消全部选择后恢复显示。点击单视频仍只播放所选 P；整合集播放按当前视频排序，再按各视频 P 序号展开。整合集操作会先读取完整目录和分 P，显示进度并支持中止；部分视频失败时可重试，或继续处理其余视频。播放准备完成前不会替换当前队列。

「复制为普通播放列表」会先让你填写名称，再复用多 P 导入选择；所选音轨加入音频库后组成独立列表，之后可自行编辑，不再跟随远端更新。在线列表本身不提供改名、拖动或单项移除，「加入播放列表」的选择弹窗只展示普通播放列表。

取消收藏只移除在线列表及目录缓存，已加入音频库的曲目、下载文件、字幕和当前队列保留。有之前读取的分 P 信息及有效本地音轨时可离线播放；单视频离线操作仅提供已有本地文件的 P，整视频批量操作需要该视频全部目标 P 的本地副本。

## 在线搜索

在线搜索可以在「作品 / B 站 / YouTube」之间切换，分别保留输入、结果和滚动位置。「作品」默认显示来自 asmr.one 的热门作品。重新搜索（包括相同条件）、改变筛选或排序时回到列表顶部并重新读取第一页；作品搜索的折叠搜索栏也会展开。追加下一页、切换来源和从详情返回不会主动回顶。

输入关键词后，应用会同时查询 asmr.one 和 DLsite，并按作品编号合并结果：

- 两边都有时，卡片使用 asmr.one 的声优、标签和发售信息。
- 只有 DLsite 有时，卡片使用商店搜索结果中的标题、社团和封面。
- 卡片底部显示 RJ 号、标签和放不下时的「+N」，不再单独标来源。
- asmr.one 明确表示未收录时，卡片标注「asmr.one 未收录」。连接失败不算未收录。

### 筛选

- 标签只能从固定列表中选择。列表项是编号加中文名，编号前的 0 要保留，例如 `073`。输入框只用于过滤这份列表，不会作为普通关键词。已添加的编号不再出现在列表中。多个标签按「同时满足」处理。
- 声优和社团由用户输入。
- 「有字幕」只影响 asmr.one。
- 「全年龄」同时限制两边：asmr.one 加 `$age:general$`，DLsite 只查全年龄分区。
- 排序有 11 种：发售日（新→旧）、最新上架、发售日（旧→新）、销量（高→低）、价格（低→高）、价格（高→低）、评分（高→低）、评价数（多→少）、RJ 号（大→小）、RJ 号（小→大）和随机。DLsite 有对应排序时使用对应排序，没有时使用默认趋势。

### 作品详情

作品详情和音频库作品页用同一套头部：封面、标题、RJ 号、社团、声优、发售日和标签。已经购买时，RJ 号旁边有「已购买」。底部五个菜单和播放条保持显示。返回在左上角，「在浏览器打开作品页」在右上角的「更多」里。「加入音频库」在右下角；已经在音频库里时显示「已在音频库」，不能再点。

头部下面依次是图库、内容试听和文件。文件区与音频库作品页共用两层滚动布局，文件标题、来源选择和从「根目录」开始的路径栏位于文件列表之外。路径栏可直接跳到祖先目录，路径太长时自动露出当前目录。列表和播放队列按名称排序；进入子目录从开头显示，返回父目录时在文件读取完成后恢复位置，左上角返回和系统返回都逐层上移。每首旁边是下载图标，下载完成后变成勾。

- 图库：来自商品页和商品信息中的主图、样品图。使用移动数据时先不加载，需要点「加载图片（使用移动数据）」；连接 Wi-Fi 时直接显示。点缩略图可打开大图并用双指缩放，返回后保留浏览位置。打乱过的图片不会还原。
- 内容试听：从 chobit 的试听页读取。没有试听时显示「暂无试听」。压缩包形式的试听不能播放。
- 文件：通过来源分段按钮切换 asmr.one 和 DLsite Play；已解压的原始文件仍归在 DLsite Play 下。asmr.one 找不到这部作品，并且明确表示未收录时，文件区显示「asmr.one 未收录」，图库和试听仍然显示。其他连接失败只提示错误，不会当作未收录。

已登录并且购买过这部作品时，文件可以在「DLsite Play」和「asmr.one」之间切换。默认显示 Play。两边文件名相同也视为两首，下载状态分别记录。未购买的作品没有可用的播放或下载地址。

点单首只播放，不会自动加入音频库。点「加入音频库」才会把整部作品加入音频库。

Play 会跳过隐藏内容、打乱过的文件、没有优化音轨的文件、切片视频和电子书页。试听地址不会携带 DLsite 登录凭证。

### B 站

打开 UP 主后，可以切换「投稿 / 合集·系列」，各自保留结果和滚动位置。点合集进入独立详情页，可浏览内容、收藏在线列表，以及播放、加入音频库、下载和复制。

切到「B 站」，可以在「视频 / UP 主」之间切换。视频支持关键词、BV 号和含 BV 的视频链接；UP 主支持昵称、数字 UID 和 `space.bilibili.com` 主页链接。明确的视频或主页链接优先识别；视频模式中的纯数字按关键词搜索，也可用 `UID:数字` 直接打开 UP 主投稿。

- 视频关键词搜索支持「综合排序 / 最多播放 / 最新发布 / 最多弹幕 / 最多收藏 / 最多评论」，以及全部、10 分钟以下、10–30 分钟、30–60 分钟、60 分钟以上的时长筛选。改变排序或时长后从第一页重新读取并回到顶部；切换来源、模式或从详情返回保留选择和位置。BV 直达不受筛选限制，UP 主搜索、投稿及合集维持原有规则。应用重启后恢复默认筛选。
- 视频展示封面、标题、作者、时长及加入音频库／下载状态。UP 主展示头像、昵称、简介、UID、粉丝数和投稿数；点击后查看最新投稿，返回恢复原搜索位置。
- 点视频只播放所选音轨，不自动加入音频库，也不播放整份结果。多 P 视频先单选要播放的分 P。
- 「更多」可「加入音频库」或「下载」。加入音频库、收藏夹导入、剪贴板及搜索下载遇到多 P 时，共用「分开导入 / 统一导入」选择。分开导入可逐 P 勾选，默认全选；统一导入包含全部 P，在音频库显示为带「多 P」标签的一个视频项。同一时间只处理一个选择，上一个还没确认或取消时，其他入口会提示「请先完成当前的导入选择」，不会没有反应地等着。长按视频可批量操作，逐视频选择方式；读取失败的项目单独说明，其余内容可继续。
- 从搜索页下载后按所选方式导入。分开导入逐 P 在成功后加入音频库；统一导入等全部目标 P 就绪后才加入整视频项，部分失败保留任务与完成文件用于重试，支持重启恢复。相同 BV/CID 复用曲目、已缓存信息和正在下载的任务。
- 点击统一视频项进入分 P 页面，按 P 序号浏览，可以多选播放、加入播放队列、下载、加入播放列表或删除下载副本；不能单独从音频库移除部分 P，可以确认后移除整个视频。
- 再次导入可确认切换组织方式。统一导入时把该视频已有 P 一并归组；拆分时保留原组全部已有 P 并放回原组父目录，勾选只控制新增内容。曲目编号、下载、字幕、队列和播放列表关联保留。取消确认不修改内容。
- 现有收藏夹的「下载音轨」继续只下载文件，不自动加入音频库。两种入口共用已有下载、字幕缓存、播放、分享和删除流程。
- 列表滚动加载后续页面；失败保留已读内容，可重试当前页。读取时可以「中止」，随后点「加载更多」继续。B 站访问受限时会显示错误，不会当作没有投稿。

### YouTube

切到「YouTube」，输入关键词、视频编号、视频链接或播放列表链接后点「查找」。搜索最多读取 3 页、40 个视频；播放列表最多 5 页、200 个视频，不保证读完整份列表。

- 点视频只播放这一首，不自动加入音频库，也不把整个搜索结果加入队列。可以后台播放和拖动进度。
- 每行「更多」可「加入音频库」或「下载」。长按进入多选，也可全选后批量下载。
- 下载完成后自动加入音频库；已加入音频库的同一视频会更新本地路径，不重复添加。下载按小段读取，断流后自动重试当前段，保留已经完成的部分。播放已下载曲目时优先读取本地音轨。
- 正在读取列表时可以「中止」；下载任务在右上角下载入口查看，可以中止或重试。失败和中止不新增曲目，已加入音频库的在线曲目保留。
- 只选独立 MP4 音轨，不下载带视频的兜底格式、WebM/Opus，也不转码。没有独立音轨会提示不可用。
- 需要处理播放地址签名时，使用系统 WebView 执行脚本，无需安装 Node.js。系统 WebView 不可用或版本过旧时会提示更新。
- YouTube 的验证可能拒绝播放或下载，即使搜索能返回结果，也不代表可以取得媒体文件。遇到需要登录或验证的提示，可在「我的」更新 Cookie；当前没有 PO Token 支持，更新 Cookie 也不保证成功。
- 不读取 YouTube 自带字幕；下载后的音轨可以沿用「生成字幕」「生成字幕和翻译」。删除已下载文件会保留在线曲目，并清理其生成字幕和完成记录。

## 我的

### YouTube 登录信息

YouTube 卡片提供「保存 Cookie」「更新 Cookie」「退出登录」「喜欢的视频」「稍后观看」。退出登录前会二次确认。从浏览器复制 `youtube.com` 的整段 Cookie，在弹窗点保存之前不参与请求。登录信息加密保存在手机，不会自动更新，也不使用应用内 Google 登录。

「喜欢的视频」和「稍后观看」需要登录信息，打开后可以单首播放、加入音频库或多选下载。保存、更新或退出登录时，会中止旧列表请求并清掉旧账号的列表结果。保存后会检查登录状态；“已保存”不等于已确认登录。

### DLsite

DLsite 登录在应用内的网页里完成：点「网页登录」打开 DLsite 登录页，账号登录和 Cloudflare 验证都在这一页完成，登录后点右上角「完成」。退出前会二次确认。保存前会去掉 Cloudflare 的验证 Cookie，应用不保存密码。也可以粘贴整段 Cookie，「使用 Cookie」默认收起。登录后不会自动列出已购作品；点「查看已购买作品」进入单独页面，再点其中一部打开在线作品页。

### B 站

B 站登录也在「我的」页，可以扫码登录、填写 SESSDATA，或粘贴整段 Cookie。扫码登录后，应用会在需要时自动更新登录信息；手动填写的 SESSDATA 或 Cookie 不会自动更新。自动更新失败时，登录卡片会显示「自动续期失败，请重新登录」，重新扫码或粘贴新凭证后提示消失；失败后 10 分钟内不会反复重试。输入内容会被遮住，可以保存或退出登录；退出登录前会二次确认。

点「查看 B 站收藏夹」进入单独页面。选中视频后，可以「加入音频库」，也可以只「下载音轨」。导入的曲目放在音频库最外层。收藏夹按分 P 显示新增下载任务数，处理失败按视频计数。

## 下载与任务

可以从以下位置发起下载：

- 音频库中单首的「更多」
- 长按多选后的「下载」；选中的文件夹会包含其中的音频
- 在线作品文件夹的「下载到本地」
- 作品详情中每首旁边的下载按钮
- 收藏夹中选中视频后的「下载音轨」
- 正在播放页的「下载音轨」

已经在本机或正在下载的内容会跳过。本机文件不会加入下载队列。下载完成后，文件保存在应用自己的目录中，之后播放会读取本地文件。B 站只下载音轨，不下载视频。

下载与任务页顶部用与作品页相同的分段选择切换「音频 / 字幕任务」。默认显示音频，每个分类分别记住滚动位置，列表不再重复显示「下载」或「生成字幕」标题；音频页包含普通下载和 DLsite 完整原始包，字幕任务页包含听写和翻译任务。每一行用标签显示排队、下载中、完成或失败，失败的任务可以在右侧重试或删除，已完成的单文件任务可以点开播放。删除前会二次确认；删除完整原始包任务会同时清掉它已经下载的压缩包，之后重试需要从头下载。DLsite 完整原始包作为一个作品任务显示解析下载地址、下载、解压和整理入库阶段，可以中止；整包任务本身不作为音频播放，解压后的音频从作品页或下载管理播放。

DLsite 部分文件下载会先提示 Play 音频可能经过压缩，提供「下载完整原始包」「仅下载所选文件」「取消」；音频库单曲、多选和在线作品详情的下载按钮使用同一选择。混合来源多选在确认后才创建下载，选择完整原始包时按作品去重。仅存在于原始包、没有 Play 音轨的文件只能下载完整原始包；试听不弹出此选择。

完整原始包支持 ZIP、RAR 及 RAR 分卷、自解压包，分卷按顺序逐卷获取并下载，全部完成后统一解压；不会运行自解压程序。为控制手机内存，RAR 字典上限为 64 MiB，超出限制或使用不支持格式时会失败。解压并加入音频库成功后删除压缩包，普通失败保留已下载的包用于重试；已确认损坏的包会清理并在重试时重新下载。原有本地副本和关联不受失败影响，也不会自动改下压缩音轨。下载和解压需要同时容纳压缩包与原始文件的空间。

失败任务的压缩包暂存会一直保留，方便重试时接着下载；不再需要时可以在下载与任务页删除该任务回收空间。应用启动时也会清理没有对应任务的残留暂存目录，已解压并加入作品的原始文件不受影响。

包里某个文件已经关联到其他曲目时，会跳过这个文件、保留原来的关联，其余文件照常加入作品，任务显示完成并提示有多少个文件保持不变；不会因为一个冲突让整个包反复失败。

DLsite Play 在线播放和部分文件下载会先换取带时效的地址及凭证，地址过期或被拒绝时会再换一次；原始包使用独立的官方下载入口。两种方式登录失效时都会提示重新登录。原始包使用独立的电脑版请求，单压缩包作品已确认可在真机下载，下载跳转、分卷链接和附件响应头也已核对；分卷完整下载与解压仍待真机验证。

下载与任务页的「字幕任务」分类显示听写和翻译任务：

- 听写进行中显示「听写中」；这次听写之后还要翻译时，显示「翻译中」。
- 对已有日文字幕单独发起翻译时，会另开一条任务，失败时显示「翻译失败」。
- 听写完成但翻译失败时，显示「听写已完成，翻译失败」，并可以查看模型返回。
- 失败的听写可以重试；排队中或进行中的听写、翻译可以中止。

中止只会停止手机上的这次请求。自部署服务（Qwen3-ASR）没有取消接口，服务上已经开始的任务会继续完成；`SenseVoiceSmall` 在当前片段识别结束后停止。

## 设置

设置页分成「外观」「存储」「字幕」和「应用」四组。「外观」里是主题模式和主题色，「存储」里是下载管理和清理缓存，「字幕」里是听写和翻译，「应用」里是关于和检查更新。

### 外观

「设置 → 外观」可以调整：

- 主题模式：跟随系统、浅色、深色。选择后立即生效，状态栏和导航栏图标也跟着变。
- 主题色，三选一：
  - 跟随系统取色：Android 12 及以上使用系统壁纸生成的颜色；更低版本用默认靛蓝。这是默认选项。
  - 跟随当前播放封面：取封面里最醒目的颜色，换曲目时平滑过渡。封面几乎是黑白灰、没有封面或还没播放时，保持上一次的颜色，从未取到过则用默认靛蓝。
  - 自选颜色：靛蓝、天蓝、青绿、草绿、琥珀、橙、绯红、粉、紫、棕、灰蓝。

设置保存在应用自己的偏好里，重启后仍然保留。

### 下载管理

「设置 → 下载管理」顶部可切换「音频 / 字幕」，默认显示「音频」，两个分类分别记住滚动位置。「音频」列出已下载的 asmr.one / DLsite / YouTube 音频和 B 站音轨。「字幕」列出应用生成的字幕（包括保留的字幕）以及作品下载目录中的 lrc/srt/vtt 文件。每行显示文件大小，生成字幕显示为音频名加 `.json`。

可以在当前分类按文件名、编号或作品名搜索，切换分类时保留搜索词。长按进入多选，可以删除或分享；只选中一项且该项带有作品编号时，还可以打开对应作品。退出多选后可切换分类。

删除音频时会删除本地文件和已完成的下载记录，作品本身仍保留在音频库中。如果这些音频带有生成的字幕，会先问是否一并删除；选择保留时字幕仍留在「字幕」分段，可以之后单独删除，重新下载同一音频时会自动匹配。不会删除进行中的听写，也不会删除下载目录中原有的 lrc/srt。只删除字幕行时，不会删除音频。

### 听写和翻译

听写和翻译在同一个页面配置。

#### 听写

听写支持三种模型。每个模型分别保存地址和 API Key；线上模型只填 API Key，自部署服务填地址和 API Key，本机模型两者都不需要。切换模型后，输入框只显示该模型已保存的内容；保存和清除也只作用于当前模型。进行中的任务继续使用它自己的模型和 API Key。

- `qwen-audio-3.1-asr`：线上模型，只填 API Key。请求固定发往 `https://dashscope.aliyuncs.com`。无论音频多长，都会先上传到临时存储，再轮询结果；超过 1GB 不上传。轮询最多等 30 分钟，服务端一直没有结果时任务显示「听写超时，请重试」，不会一直占住后面的听写任务；等待期间点「中止」仍显示「已中止」。
- `Qwen3-ASR`：需要填写地址和 API Key。应用先读取服务上的模型名，再请求 `/v1/audio/transcriptions`，语言为日语。返回分段时间时按段生成字幕；只返回整段文字时，写成覆盖整首时长的一条；没有时长也没有分段时间时，记为「没有分段时间」。
- `SenseVoiceSmall`：完全在本机运行的离线模型，不需要地址和 API Key。第一次使用前先在设置里下载模型（约 160MB 下载、230MB 占用，从 GitHub 下载到手机）；之后按静音把长音频切成不超过 28 秒的片段逐段识别，再拼回整首时间轴，语言为日语。删除模型前会二次确认。详见 [docs/whisper-api.md](docs/whisper-api.md)。

保存听写地址时不会自动补 `/v1`；`Qwen3-ASR` 只在请求时补。

`Qwen3-ASR` 的地址是局域网、本机或 `.local` 时，Android 会询问是否允许访问本地网络，需要允许。公网地址和 `SenseVoiceSmall` 不会询问。

#### 翻译

翻译只支持通用大模型，可选「千问 AI 平台」或「DeepSeek」。两个平台的请求地址固定，不需要填写：

- 千问 AI 平台：`https://maas.qianwenaiapi.com/compatible-mode/v1/chat/completions`。模型名不填时使用 `qwen3.8-flash`。
- DeepSeek：`https://api.deepseek.com/chat/completions`。模型名不填时使用 `deepseek-flash`。

API Key 必须填写。两个平台的 API Key 和模型名分别保存。

深度思考默认关闭。打开后可以选择思考强度：千问 AI 平台有低、中、高三档，DeepSeek 有高、最高两档。关闭时单次请求最长等待 3 分钟，打开后最长等待 10 分钟。

日文字幕按每批最多 40 句发送，返回的每一行必须是「编号|译文」。任意一批格式不正确，整次翻译失败，已完成的批次不会保存。

「翻译后自动润色」默认关闭。打开后，翻译完成会再请求模型润色一遍；润色失败时保留刚译好的译文。查看中文字幕时，也可以手动点「润色」。手动润色不会出现在下载列表中；离开正在播放页不会中断已经开始的润色。润色失败同样保留原译文。

### 清理缓存

「设置 → 清理缓存」显示封面图片等临时缓存的占用，并允许设置上限。默认上限为 200MB，可选 100MB、200MB、500MB、1GB、2GB。

缓存占用超过上限后，应用会按文件修改时间从早到晚删除，直到回到上限以内。点「清理缓存」会立即清空这份临时缓存。

下载的音频、B 站下载音轨和字幕不在清理范围内；需要删除时，请到「下载管理」处理。

### 关于与检查更新

「设置 → 关于」显示实际安装包的当前版本和构建号。点「检查更新」只查询标签以 `android-` 开头的 [GitHub Android 正式发布](https://github.com/nanahoshi114/AudioPlayer/releases)，显示有新版本、已是最新、本机版本更高或无法比较；网络失败时可以重试。桌面端发布不参与 Android 更新检查。

点「在浏览器打开发布页」后，由用户在浏览器下载 APK 并安装。应用内只读取版本信息，不下载或安装更新。没有检查成功时，也能打开全部发布列表查看。

## 编译

用 Android Studio 打开 `Android/` 目录即可。命令行编译当前代码（在本目录执行）：

```sh
export GRADLE_USER_HOME="$HOME/.gradle"
./gradlew :app:compileDebugKotlin --no-configuration-cache
```

从仓库根目录执行时用 `Android/gradlew -p Android :app:compileDebugKotlin --no-configuration-cache`。

主要版本：Kotlin 2.2.10，Android Gradle 插件 9.4.1，compileSdk 37，minSdk 24，targetSdk 37。界面用 Jetpack Compose，本地库用 Room 2.8.5，播放用 Media3 1.10.1，网络用 OkHttp 4.12.0。依赖仓库先走阿里云镜像。

本机若是 JDK 25，Kotlin 会退回到 24 来编译，这是提示，不是失败。
