# 音频播放器

**把本机、B 站、asmr.one 和 DLsite 的声音，收进一个播放器。**

如果你收藏本机音声，也听 B 站视频里的音轨，还在 [asmr.one](https://asmr.one/) 和 DLsite 之间找作品，这个应用就是为这条听音路线准备的：四个来源进同一个音频库，输入关键词就能同时查 asmr.one 和 DLsite，买过的作品登录后直接播放；缺字幕时，选一个听写接口生成日文字幕，再译成中文。

应用名「音频播放器」，包名 `com.nanahoshi.audioplayer`。

## 亮点

- **一个库，四个来源都装得下**：本机文件、B 站音轨、asmr.one 作品和 DLsite 已购内容共用一套文件夹，搜索、筛选、排序、多选都在同一页完成。旧文件夹还能「识别为作品」，补上封面、社团和曲目信息，本地文件一个不动。
- **搜一次，两边一起给答案**：输入关键词，asmr.one 和 DLsite 同时查，同一部作品合并成一张卡片，并标出「DLsite 也有」或「asmr.one未收录」。标签、声优、社团、全年龄、字幕条件都能叠加，11 种排序随手换，不用在两个网页之间复制粘贴。
- **买过的，登录就能听**：DLsite 支持账号密码或 Cookie 登录。已购作品会标出「已购买内容」，文件可在 DLSite Play 和 asmr.one 之间切换，图库、试听和下载都在作品页完成。
- **字幕不用从零开始**：本地同名字幕、asmr.one 文本、B 站自带字幕都会自动接上。没有现成字幕时，选一个听写接口生成日文字幕；点一句跳一句，有译文时随时在中文和日文之间切换。
- **听写和翻译，用你顺手的服务**：`whisper-1`、`whisper（本地部署）`、`qwen-audio-3.1-asr`、`Qwen3-ASR`、本机任务接口五种接法，每个模型分别保存自己的地址和密钥，线上模型只填 API Key。听写和翻译可以一起做，也能事后单独翻译；退出播放页不会打断正在进行的翻译。
- **下载、缓存、清理，都心里有数**：单首、多选、整部作品缓存都能下，B 站只保存音轨，不占视频空间。进度可看、可中止、失败可重试；已落盘的文件在「下载管理」里搜索、导出或删除。
- **播放稳，边界也清楚**：前台服务加通知栏控制，队列可拖动、定时可关闭。没点「保存」的在线内容不会写进库；密码只换登录凭证，不保存；未购买的作品不会拼下载地址，打乱的图片也不会拼回去。

## 快速开始

### 1. 装到手机

Android 7.0（API 24）及以上。用 Android Studio 打开工程，连上手机直接运行；需要安装包时，在 Android Studio 里生成签名 APK。命令行编译见文末[编译](#编译)。

### 2. 把想听的内容放进来

- **本机**：音频库右上角「+」→「选择文件导入」或「选择文件夹导入」，后者会保留原来的目录结构。
- **B 站**：同一个「+」里粘贴 BV 号或视频链接；也可以先在「我的」登录，再从收藏夹导入。
- **asmr.one**：输入 RJ 号导入整部作品，或到「在线搜索」按关键词、标签、声优、社团找。
- **DLsite 已购**：在「我的」登录后，点「查看已购买作品」，选中一部即可听或下载。

### 3. 让字幕跟上

打开「我的」里的「听写」，选一个模型，填好所需的地址和口令并保存；`whisper-1` 和 `qwen-audio-3.1-asr` 是线上模型，只填 API Key。播放时点「生成字幕」或「生成字幕和翻译」，已有日文字幕也可以单独「生成翻译」。听写或翻译服务在局域网、本机或 `.local` 时，首次访问要允许本地网络。

### 4. 想离线就下载

在单首「更多」、多选「下载」、作品夹「缓存到本地」或播放页「缓存音轨」里发起。进度在右上角下载图标里看；下完的文件交给「我的 → 下载管理」，搜索、导出、删除都在那里。

## 界面

打开应用，底部是四个分页：音频库、播放列表、在线搜索、我的。这四页上方有标题栏，右上角是进行中的下载，底下是正在播放的小条。点进作品详情、已购买列表、收藏夹、正在播放、下载、下载管理、文件预览时，底栏会让开，变成单独一页。

音频库和在线搜索顶部的搜索、筛选，手指往上滑会收起来，往下滑再出来。排序、导入，以及多选时的操作条，一直留在上面。

## 音频库

音频库按文件夹一层层展开，本地文件、B 站音轨和在线作品可以混放在一起。

想往库里加东西，点右上角「+」：

- 新建文件夹
- 选择文件导入
- 选择文件夹导入（可以保留原来的文件夹结构）
- 输入 BV 号或视频链接，只导入、不立刻播放
- 输入 RJ 号，导入 asmr.one 上的整部作品

顶部可以按名称或按加入时间排序，也可以在「全部 / B站 / asmr.one / 本地」之间筛选。

- 「B站」只列出 B 站音轨，不再显示文件夹。
- 「asmr.one」只列出带作品编号的在线作品文件夹，包含从 DLsite 保存进来的作品，不把里面的单首拆开。
- 「本地」仍按文件夹浏览。在线作品文件夹会被藏起来，文件夹里也只留本机音频。如果当时正站在某个在线作品里面，会先退到最近的普通文件夹。
- 搜索时也会套用当前筛选。搜纯数字时，会额外对上作品编号。

点进已保存的在线作品，还留在音频库里：上面是封面、标题、社团、声优、发售、标签，旁边有「详情页」。图库和试听不在这一页。子文件夹也继续在库里往下走。空的已购作品文件夹会再去读一次文件；读取时提示「正在读取文件…」，两边都没有文件时提示「没有读到这个作品的文件」。

长按进入多选。操作有：下一个播放、加到末尾、加入播放列表、下载、移除。选中的那一项会把完整名字换行显示出来，没选中的仍只显示一行。点进子文件夹从这一层开头看；返回时，上一层还停在刚才滑到的位置。每一层各自记着。从上一层再次点进同一个文件夹，会重新从开头看。

单条「更多」里，在线音频可以单独下载；带作品编号的文件夹可以「缓存到本地」。图片和文本可以打开预览。字幕文件不单列出来，对应音频上会标「有字幕」。

### 识别为作品

本地文件夹还不是作品时，单条「更多」里有「识别为作品」。填 RJ 号后，应用先看 DLsite：已经买过、登录还有效、文件树也读得到时，先对照 DLsite 的文件。没买过、对不上，或 DLsite 连不上，再对照 asmr.one。DLsite 登录已失效时会直接提示重新登录，不会当成没买过。

- 本地可以少一些文件或文件夹，不能多出作品里没有的内容。多出来的会一起写在提示里。
- 对上 DLsite 时提示「DLsite匹配成功」，曲目标成 DLsite；对上 asmr.one 时提示「asmr.one匹配成功」。
- DLsite 没连上、asmr.one 也对不上，提示「DLsite未连接且asmr.one匹配失败」。两边都没对上，提示「DLsite/asmr.one均匹配失败」。
- 对上以后曲目编号和本地路径保持不变，已经生成的字幕还在。名称比较会忽略全角、半角和大小写。

## 播放

退到后台也能继续播，通知栏随时可以控制。正在播放页有封面、进度、上一首 / 暂停 / 下一首，以及定时关闭；时间一到会自动停止，并弹出提示。

当前播放队列可以拖动排序、删一首或清空。队列里可以放还没保存进库的在线音频，关掉应用前这段队列还在。

B 站音轨如果还没缓存，正在播放页会显示「缓存音轨」。缓存只保存音频，不下视频；缓存过的曲目之后直接读本地文件。收藏夹里也能选中后「缓存音轨」。

已有字幕只接已经在库里的音频：

- 本地文件：找同一层里同名的字幕。
- asmr.one：找同一文件夹里同名的文本。
- B 站：用视频自己的字幕。
- DLsite 音轨本身没有现成字幕。

没有这些字幕时，正在播放页可以「生成字幕」或「生成字幕和翻译」。手机里已经有文件就直接上传。asmr.one、DLsite 和 B 站音轨如果还没下载，会先加入缓存下载，等文件到了再听写。没有本地文件、也不能下载的音频不能生成。

生成结果按文件内容保存。同一文件、同一听写地址、同一模型已经完成、字幕文件还在时，不会重新上传；换地址或换模型会再跑一次。点开字幕可以看全文，当前句会高亮，点某一句会跳到那句开头；返回后还在这一页。正在播放页上的当前句仍用来打开全文列表。有中文译文时可以在「中文 / 日文」之间切换。只有日文时可以「生成翻译」。应用生成的字幕可以删除，之后再生成。听写没有人声时显示「没有听出人声」，也可以删掉重来。退出正在播放页不会中断已经开始的翻译。

## 播放列表

把常听的内容攒成播放列表：可以新建、改名、删除，曲目顺序随手拖动。整张列表可以替换当前播放，或接到当前队列末尾；也能从音频库把选中的音频加进来。

## 在线搜索

还没想好听什么，就先看热门；热门列表来自 asmr.one。

输入关键词后，asmr.one 和 DLsite 同时查，再按作品编号合并。两边都有时，卡片用 asmr.one 的声优、标签和发售信息，并标上「DLsite 也有」。只有 DLsite 有的，用商店搜索结果里的标题、社团和封面；asmr.one 明确说没收录时，卡片上标「asmr.one未收录」。连接失败不算「未收录」。

筛选：

- 标签只能从固定列表里点，列表项是数字编号加中文名。编号前面的 0 要留着，例如 `073`。输入框只用来在这份列表里过滤，不会变成普通关键词。已经加过的编号不再出现。多个标签是「同时满足」。
- 声优、社团仍是自己输入的文字。
- 「有字幕」只影响 asmr.one。
- 「全年龄」两边都加限制：asmr.one 加 `$age:general$`，DLsite 只查全年龄分区。
- 排序有发售日、最新收录、发售日-正序、销量、价格-正序、价格、评分、评价数、RJ号、RJ号-正序和随机。DLsite 对得上的用对应排序，对不上的用它的默认趋势。

作品详情是一整页往下滚，返回和「保存」固定在顶上。

- **图库**：来自商品页和商品信息里的主图、样品图。手机开着流量时先不加载，要点「预览」；连着 Wi-Fi 时直接显示。
- **内容试听**：从 chobit 的试听页读取。没有试听时显示「没有试听」。压缩包形式的试听不能播。
- **文件**：标题会写明来自 asmr.one 还是 DLSite Play。asmr.one 上找不到这部作品、并且对方明确说没有收录时，文件区显示「asmr.one未收录」，图库和试听仍保留。别的连接失败只提示错误，不当成「未收录」。

已登录并且这部是买过的，资料上会标「已购买内容」，文件可以在「DLSite Play」和「asmr.one」之间换。默认先看 Play。两边文件名一样也当成两首，下载状态分开记。

点单首只播放，不自动保存。点「保存」才把整部作品放进音频库。

Play 里会跳过隐藏内容、打乱过的文件、没有优化音轨的文件、切片视频和电子书页。试听地址不会带上 DLsite 的登录凭证。

## 我的

DLsite 可以用账号密码登录，也可以粘贴整段 Cookie（网站发给浏览器的登录字条）。登录后不会自动列出已购作品，要点「查看已购买作品」才打开单独一页；点其中一部会去在线作品页。

B 站登录放在同一页，可以扫码登录，也可以填 SESSDATA，或整段 Cookie。扫码登录后，应用会在需要时自动更新登录信息；粘贴的 SESSDATA 或 Cookie 不会自动更新。输入时遮住，可以保存或清除。点「查看收藏夹」打开单独一页，选中视频后可以「导入到音频库」，也可以只「缓存音轨」。导入的曲目放进库的最外层。

听写可以选五种接口。每个模型各自保存自己的地址和密钥；线上模型只填 API Key，本地服务填地址和口令。切换下拉只显示该模型已保存的内容，保存和清除也只作用于当前模型。进行中的任务继续用它自己的模型和口令。

- `whisper-1`：线上模型，只填 API Key。请求固定走 `https://api.openai.com`，模型名 `whisper-1`，语言日语，要分段时间。单次最长等待 10 分钟。文件超过 25MB 时先询问，确认后仍上传，取消则记为「已中止」。
- `whisper（本地部署）`：要填地址和口令。地址没有 `/v1` 时请求前补上，请求内容与 `whisper-1` 相同，模型名仍发送 `whisper-1`。超过 25MB 不再询问。服务不检查口令时，填任意非空内容即可。
- `qwen-audio-3.1-asr`：线上模型，只填 API Key。请求固定走 `https://dashscope.aliyuncs.com`。5 分钟以内的音频直接提交；更长的先上传到临时存储再轮询，走临时上传时超过 1GB 不上传。
- `Qwen3-ASR`：要填地址和口令。应用先读取服务上的模型名，再请求 `/v1/audio/transcriptions`，语言日语。返回分段时间时按段写字幕；只有整段文字时写成覆盖整首时长的一条；没有时长也没有分段时间时记为「没有分段时间」。
- `本机任务接口`：要填地址和口令，按 [docs/whisper-api.md](docs/whisper-api.md) 提交到 `POST /jobs`，再查询进度和字幕。

没保存过模型时，地址路径去掉末尾斜杠后以 `/v1` 结尾且域名是 `api.openai.com` 的算 `whisper-1`，其他以 `/v1` 结尾的算 `whisper（本地部署）`，其余算本机任务接口。保存听写地址时不会自动补 `/v1`。

翻译填写地址、口令和模型名，只支持通用大模型。地址未以 `/v1` 结尾时，保存后会自动补上。应用请求 `{地址}/chat/completions`，模型名必须与服务提供的名称一致。日文按每批最多 40 句发送，返回的每一行必须是「编号|译文」。任一批格式不对，整次翻译失败，已完成的批次不会保存。单次最长等待 3 分钟。模型若还在思考，可能超过时限而失败。

听写或翻译地址是局域网、本机或 `.local` 时，Android 会询问是否允许访问本地网络，需要允许。公网地址不会询问。

## 下载

想离线听，可以从这些地方发起下载或缓存：

- 音频库里单首的「更多」
- 长按多选后的「下载」（选中的文件夹会带上里面的音频）
- 在线作品文件夹的「缓存到本地」
- 作品详情里每一首旁边的下载
- 收藏夹里选中视频后的「缓存音轨」
- 正在播放页的「缓存音轨」

已经在本机、或正在下载的会跳过。本机文件不会进这个队列。下完的文件放在应用自己的目录里，之后播放走本地文件。B 站只保存音轨，不保存视频。下载页能看进度，失败可重试，下完的可以点开播放。

DLsite 已购文件每次播放或下载前，会先换一个带时效的地址和配套凭证。地址过期或被拒绝时会再换一次；登录失效会提示重新登录。

下载列表后半段是「生成字幕」。听写进行中显示「听写中」，这次听写接着翻译时显示「翻译中」。对已有日文单独翻译时另开一条，失败显示「翻译失败」。听写完成后翻译失败，显示「听写已完成，翻译失败」，并可以查看模型返回。失败的听写可以重试。排队或进行中的听写、翻译可以中止。中止停的是手机上的这次请求；本机听写服务没有取消接口，服务上已经开始的转写会自己跑完。

## 下载管理

下完的文件不用去文件管理器里翻。「我的」里的「下载管理」集中列出已经在手机上的 asmr.one / DLsite 音频、缓存的 B 站音轨、这些音频的生成字幕，以及作品下载目录里的 lrc/srt/vtt。每一行带上文件大小；`filesDir/subtitles` 里其余生成字幕也会列出来，列表名是音频名加上 `.json`。

顶部可以按文件名、RJ 号或作品名搜索。长按进入多选，可以删除或导出；只选中一项且带作品编号时，还能打开对应作品。删音频时会清掉本地文件和已完成的下载记录，作品留在库里，同时删这首的生成字幕；不删进行中的听写，也不删下载目录里原有的 lrc/srt。只删字幕行时不会删音频。

## 代码怎么分

| 位置 | 做什么 |
| --- | --- |
| `ui/library` | 音频库、收藏夹导入、图片和文本预览 |
| `ui/playlist` | 播放列表 |
| `ui/player` | 正在播放、底部小条、字幕按钮 |
| `ui/asmr` | 在线搜索、作品详情、我的、已购买列表 |
| `ui/download` | 进行中的下载、听写、翻译；已落盘文件的下载管理 |
| `playback` | 播放服务、在线音频读取、字幕 |
| `bilibili` | B 站视频、收藏夹、字幕、扫码登录 |
| `asmr` | asmr.one 作品、搜索、音轨地址 |
| `dlsite` | 商店搜索、商品页、登录、已购 Play 文件、标签表、试听 |
| `data` | 音频库、下载、已落盘文件、登录信息、听写、翻译 |
| `data/db` | Room，当前第 12 版 |
| `AppGraph.kt` | 在 `Application.onCreate` 里组装。顺序是 db、credentials、bilibili、asmr、dlsite、librarySort、library、downloads、subtitles、translator、whisper、player |

本地库存这些东西：文件夹、音轨、作品里的图片和文本、下载任务、听写任务、翻译任务、播放列表、当前播放队列、上次播放到哪。在线作品的同一首，用「来源 + 作品 + 文件」区分，避免 asmr.one 和 DLsite 撞成同一条。

接口对照记在：

- [docs/asmr-one-api.md](docs/asmr-one-api.md)
- [docs/dlsite-api.md](docs/dlsite-api.md)
- [docs/whisper-api.md](docs/whisper-api.md)
- [docs/youtube-api.md](docs/youtube-api.md)（只读调查，播放器尚未接入 YouTube）

## 编译

想自己跑起来，用 Android Studio 打开工程即可。命令行编译当前代码：

```sh
export GRADLE_USER_HOME="$HOME/.gradle"
./gradlew :app:compileDebugKotlin --no-configuration-cache
```

主要版本：Kotlin 2.2.10，Android Gradle 插件 9.4.1，compileSdk 37，minSdk 24，targetSdk 37。界面用 Jetpack Compose，本地库用 Room 2.8.5，播放用 Media3 1.10.1，网络用 OkHttp 4.12.0。依赖仓库先走阿里云镜像。

本机若是 JDK 25，Kotlin 会退回到 24 来编译，这是提示，不是失败。
