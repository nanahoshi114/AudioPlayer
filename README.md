# 音频播放器

应用名「音频播放器」，包名 `com.nanahoshi.audioplayer`。

这是一个 Android 音频播放器，支持本机文件、B 站音轨、[asmr.one](https://asmr.one/) 作品和 DLsite 已购内容；可以生成日文字幕、翻译成中文，也能把在线内容缓存到手机离线播放。

## 快速开始

1. **安装**：Android 7.0（API 24）及以上。到 [Releases](https://github.com/nanahoshi114/AudioPlayer/releases/latest) 下载最新的 APK 安装。想自行编译，见文末[编译](#编译)。
2. **导入内容**：在音频库点右下角「导入」，可以导入本机文件或文件夹、输入 BV 号导入 B 站音轨，或输入 RJ 号导入 asmr.one 作品。DLsite 已购内容需要先在「我的」登录，再从「查看已购买作品」打开。
3. **配置字幕（可选）**：打开「设置 → 听写和翻译」，选择听写模型并保存；需要翻译时，在同一页选择翻译平台并填写口令。播放时如果没有现成字幕，可以点「生成字幕」或「生成字幕和翻译」。听写地址在局域网、本机或 `.local` 时，首次访问需要允许本地网络。
4. **下载（可选）**：在单首「更多」、多选「下载」、作品详情、收藏夹或正在播放页发起下载。有进行中的下载、听写或翻译时，右上角下载图标会显示数量；完成后到「设置 → 下载管理」查看。

## 界面

打开应用后，底部有五个分页：音频库、播放列表、在线搜索、我的、设置。五页顶部都有标题栏，右上角是下载入口；有进行中的任务时图标上显示数量。底部正在播放的小条是一张圆角卡片，卡片底边显示播放进度。

作品详情、音频库里的作品页、已购买列表、收藏夹、正在播放、下载、下载管理、听写和翻译、清理缓存、文件预览是单独页面。作品页和作品详情会留下底部五个菜单和播放条，只把顶部标题栏滑走。其余页面离开五个主页面时，顶栏和底栏都会滑出隐藏。

音频库和在线搜索页的搜索、筛选栏，向上滑动页面时收起，向下滑动时重新出现；松手时如果没收起一半，会弹回完全展开。音频库的排序在搜索栏旁的图标里，和搜索栏一起收起。导入按钮在右下角，列表向下滚动时收成圆形。多选时，顶栏换成已选数量和操作。

## 音频库

音频库按文件夹逐层展开。本机文件、B 站音轨和在线作品可以混放在同一层。

### 导入内容

点右下角「导入」，可以选择：

- 新建文件夹
- 选择文件导入
- 选择文件夹导入，保留原来的目录结构
- 输入 BV 号或视频链接，只导入，不立即播放
- 输入 RJ 号，导入 asmr.one 上的整部作品

### 浏览与筛选

搜索栏旁的排序图标可以在名称和加入时间之间切换。搜索栏下方可以在「全部 / B站 / asmr.one / 本地」之间筛选。进入子文件夹后，路径显示为面包屑，点某一层会回到那一层。

- 「B站」只显示 B 站音轨，不显示文件夹。
- 「asmr.one」只显示带作品编号的在线作品文件夹，包括从 DLsite 保存的作品，不展开里面的单首。
- 「本地」按文件夹浏览，隐藏在线作品文件夹，文件夹内只显示本机音频。如果当前位于在线作品文件夹内，会先退到最近的普通文件夹。
- 搜索时会套用当前筛选；搜索纯数字时，还会匹配作品编号。

### 作品页

点已保存的在线作品会打开单独的作品页，音频库列表停在原来的位置。底部五个菜单和播放条保持显示。

页面上方是封面、标题、RJ 号、社团、声优、发售日，标签超过 8 个时可以展开。图库和试听不在这一页，在右上角「更多」里点「在线详情」打开。下面是「缓存到本地」、「识别本地文件夹」和文件列表。子文件夹照常展开，路径显示为面包屑，根是「文件」。在子文件夹里按返回会先回到上一级，到作品根再退出页面。

作品同时有 DLSite 和 asmr.one 两套文件时，可以用「DLSite Play / asmr.one」切换。列表只显示当前这一套，点任意一首播放时，队列也只放入当前这一套的曲目。「缓存到本地」时，如果已购买（读缓存，不联网查）而且 asmr.one 里也有这部作品，会先弹窗让你选来源；缓存前如果同一文件夹里有两个音频只差扩展名（如 xx.mp3 和 xx.wav），再弹窗问下载哪种格式，没有冲突的音频照常下载。作品里已经有 Play 文件时，打开后会直接显示切换，不会因为 DLsite 连不上而一直等。

空的已购作品会重新读取文件。读取时显示「正在读取文件…」；DLsite 和 asmr.one 都没有文件时，显示「没有读到这个作品的文件」。

长按文件可以多选，操作和音频库一样。右上角「更多」里的「从音频库移除」会先确认，移除后回到音频库。

### 多选与单条操作

长按任意一项进入多选，顶栏显示已选数量。下一个播放、加到末尾、下载是图标；加入播放列表、删除已下载的文件、移除在「更多」里。只要选中了作品，下一个播放、加到末尾、下载、加入播放列表就不显示，只剩删除已下载的文件和移除；作品行「更多」里的「缓存到本地」不受影响。选中的项会换行显示完整名称，未选中的项只显示一行。

点进子文件夹时从这一层开头显示；返回后，上一层仍停在原来的位置。每一层分别记录位置。从上一层再次进入同一个文件夹时，会从开头显示。

单条「更多」中，在线音频可以单独下载；带作品编号的文件夹可以「缓存到本地」：已购买且 asmr.one 也有收录时先选来源，否则缓存当前显示的那一套（在作品外面发起、没有弹窗时，有 Play 文件就缓存 DLSite Play，否则 asmr.one）。

「删除已下载的文件」不分来源。App 下载的文件会真的删除；通过识别挂上的本地文件是你自己的，只取消识别（曲目回到在线曲目），不会删手机上的原文件。图片和文本可以预览，图片可以用双指缩放。字幕文件不会单独列出，对应音频会标「有字幕」。

### 识别为作品

作品已经在音频库里时，作品页的「识别本地文件夹」可以选手机上的一个文件夹，对照当前显示的那一套文件，对上的曲目会挂上本地文件（显示「已下载」，播放读本地文件），曲目 id 不变，原文件不动。本地可以少，不能多出作品里没有的。同一个本地文件已经挂在别的曲目上时，这次会跳过并在提示里说明。

本地文件夹还不是作品时，可以在单条「更多」里选「识别为作品」，填写 RJ 号。应用会先检查 DLsite：如果已经购买、登录有效，并且能读取文件树，就先对照 DLsite 的文件；否则再对照 asmr.one。DLsite 登录失效时会提示重新登录，不会当作没购买。

- 本地文件可以少于作品内容，不能多出作品里没有的文件或文件夹。多出的内容会写在提示里。
- 对上 DLsite 时提示「DLsite匹配成功」，曲目标记为 DLsite；对上 asmr.one 时提示「asmr.one匹配成功」。
- DLsite 未连接、asmr.one 也对不上时，提示「DLsite未连接且asmr.one匹配失败」。两边都对不上时，提示「DLsite/asmr.one均匹配失败」。
- 匹配成功后，曲目编号和本地路径不变，已生成的字幕仍然保留。名称比较忽略全角、半角和大小写。

## 播放

应用支持后台播放，通知栏可以控制播放。正在播放页从上到下是封面、标题、字幕、进度和播放控制。播放键下方是定时关闭、队列；B 站音轨尚未缓存时还有「缓存音轨」。定时关闭倒计时中会显示剩余时间，时间到后自动停止并提示。

点「队列」会从底部打开当前播放队列，可以拖动排序、删除单首。清空在标题栏右侧，需要先确认。队列里可以放入尚未保存到音频库的在线音频，关闭应用后队列仍会保留。

B 站音轨尚未缓存时，正在播放页会显示「缓存音轨」。缓存只保存音频，不保存视频；缓存后播放会直接读取本地文件。收藏夹中也可以对选中的视频执行「缓存音轨」。

## 字幕

已有字幕只对已经加入音频库的音频生效：

- 本地文件：查找同一层目录中同名的字幕。
- asmr.one：查找同一文件夹中同名的文本。
- B 站：使用视频自带的字幕。
- DLsite 音轨没有现成字幕。

### 生成字幕

没有现成字幕时，可以在正在播放页选择「生成字幕」或「生成字幕和翻译」。

- 「生成字幕」只生成日文字幕，不请求翻译。
- 「生成字幕和翻译」在听写完成后继续翻译成中文。

手机中已有音频文件时直接上传。asmr.one、DLsite 和 B 站音轨尚未下载时，会先加入缓存下载，文件到达后再听写。没有本地文件且无法下载的音频不能生成。听写和翻译接口在「设置 → 听写和翻译」中配置。

生成结果按文件内容保存。同一文件、同一听写地址、同一模型已经完成，并且字幕文件仍然存在时，不会重复上传；更换地址或模型会重新生成。退出正在播放页不会中断已经开始的翻译或润色。

点开字幕会从下方展开全文。当前句会高亮，点击任意一句会跳到该句开头，列表仍留在这一页；返回后回到正在播放页。正在播放页上的当前句也可以打开全文列表。

有中文译文时，全文顶部可以在「中文 / 日文」之间切换。切换到中文后，右上角可以点「润色」；只有日文时可以点「生成翻译」。正在翻译或润色时，这个按钮变成「中止」。应用生成的字幕可以在「更多」里删除，之后可以重新生成。听写没有检测到人声时显示「没有听出人声」，也可以删除后重试。

## 播放列表

可以把常听的内容整理成播放列表。右下角「新建」用来建列表，列表里可以改名、删除，也可以拖动调整曲目顺序。详情页的「播放」会替换当前播放队列，「加到末尾」会追加到当前队列；列表里没有「加入音频」按钮，只能在音频库里多选音频后加入播放列表。

## 在线搜索

打开在线搜索时，先显示来自 asmr.one 的热门作品。

输入关键词后，应用会同时查询 asmr.one 和 DLsite，并按作品编号合并结果：

- 两边都有时，卡片使用 asmr.one 的声优、标签和发售信息，来源标为 asmr.one。
- 只有 DLsite 有时，卡片使用商店搜索结果中的标题、社团和封面。
- asmr.one 明确表示未收录时，卡片标注「asmr.one未收录」。连接失败不算未收录。

### 筛选

- 标签只能从固定列表中选择。列表项是编号加中文名，编号前的 0 要保留，例如 `073`。输入框只用于过滤这份列表，不会作为普通关键词。已添加的编号不再出现在列表中。多个标签按「同时满足」处理。
- 声优和社团由用户输入。
- 「有字幕」只影响 asmr.one。
- 「全年龄」同时限制两边：asmr.one 加 `$age:general$`，DLsite 只查全年龄分区。
- 排序有 11 种：发售日、最新收录、发售日-正序、销量、价格-正序、价格、评分、评价数、RJ号、RJ号-正序和随机。DLsite 有对应排序时使用对应排序，没有时使用默认趋势。

### 作品详情

作品详情和音频库作品页用同一套头部：封面、标题、RJ 号、社团、声优、发售日和标签。已经购买时，RJ 号旁边有「已购买」。底部五个菜单和播放条保持显示。返回在左上角，「打开外部浏览器」在右上角的「更多」里。「保存」在右下角；已经在音频库里时显示「已在音频库」，不能再点。

头部下面依次是图库、内容试听和文件。文件来源用「DLSite Play / asmr.one」切换。每首旁边是下载图标，下载完成后变成勾。

- 图库：来自商品页和商品信息中的主图、样品图。使用移动数据时先不加载，需要点「预览」；连接 Wi-Fi 时直接显示。打乱过的图片不会还原。
- 内容试听：从 chobit 的试听页读取。没有试听时显示「没有试听」。压缩包形式的试听不能播放。
- 文件：标题会标明来自 asmr.one 还是 DLSite Play。asmr.one 找不到这部作品，并且明确表示未收录时，文件区显示「asmr.one未收录」，图库和试听仍然显示。其他连接失败只提示错误，不会当作未收录。

已登录并且购买过这部作品时，文件可以在「DLSite Play」和「asmr.one」之间切换。默认显示 Play。两边文件名相同也视为两首，下载状态分别记录。未购买的作品没有可用的播放或下载地址。

点单首只播放，不会自动保存。点「保存」才会把整部作品加入音频库。

Play 会跳过隐藏内容、打乱过的文件、没有优化音轨的文件、切片视频和电子书页。试听地址不会携带 DLsite 登录凭证。

## 我的

### DLsite

DLsite 支持账号密码登录，也支持粘贴整段 Cookie。「使用 Cookie」默认收起。账号密码只用于换取登录凭证，不会保存密码。登录后不会自动列出已购作品；点「查看已购买作品」进入单独页面，再点其中一部打开在线作品页。

### B 站

B 站登录也在「我的」页，可以扫码登录、填写 SESSDATA，或粘贴整段 Cookie。扫码登录后，应用会在需要时自动更新登录信息；手动填写的 SESSDATA 或 Cookie 不会自动更新。输入内容会被遮住，可以保存或清除。

点「查看收藏夹」进入单独页面。选中视频后，可以「导入到音频库」，也可以只「缓存音轨」。导入的曲目放在音频库最外层。

## 下载

可以从以下位置发起下载或缓存：

- 音频库中单首的「更多」
- 长按多选后的「下载」；选中的文件夹会包含其中的音频
- 在线作品文件夹的「缓存到本地」
- 作品详情中每首旁边的下载按钮
- 收藏夹中选中视频后的「缓存音轨」
- 正在播放页的「缓存音轨」

已经在本机或正在下载的内容会跳过。本机文件不会加入下载队列。下载完成后，文件保存在应用自己的目录中，之后播放会读取本地文件。B 站只保存音轨，不保存视频。

下载页分成「下载」和「生成字幕」两段。每一行用标签显示排队、下载中、完成或失败，失败的任务可以在右侧重试，已完成的任务可以点开播放。

DLsite 已购文件在每次播放或下载前，都会先换取一个带时效的地址和配套凭证。地址过期或被拒绝时会再换一次；登录失效时会提示重新登录。

下载页的后半部分是「生成字幕」任务：

- 听写进行中显示「听写中」；这次听写之后还要翻译时，显示「翻译中」。
- 对已有日文字幕单独发起翻译时，会另开一条任务，失败时显示「翻译失败」。
- 听写完成但翻译失败时，显示「听写已完成，翻译失败」，并可以查看模型返回。
- 失败的听写可以重试；排队中或进行中的听写、翻译可以中止。

中止只会停止手机上的这次请求。本机听写服务没有取消接口，服务上已经开始的任务会继续完成。

## 设置

设置页分成「外观」「存储」和「字幕」三组。「外观」里是主题模式和主题色，「存储」里是下载管理和清理缓存，「字幕」里是听写和翻译。

### 外观

「设置 → 外观」可以调整：

- 主题模式：跟随系统、浅色、深色。选择后立即生效，状态栏和导航栏图标也跟着变。
- 主题色，三选一：
  - 跟随系统取色：Android 12 及以上使用系统壁纸生成的颜色；更低版本用默认靛蓝。这是默认选项。
  - 跟随当前播放封面：取封面里最醒目的颜色，换曲目时平滑过渡。封面几乎是黑白灰、没有封面或还没播放时，保持上一次的颜色，从未取到过则用默认靛蓝。
  - 自选颜色：靛蓝、天蓝、青绿、草绿、琥珀、橙、绯红、粉、紫、棕、灰蓝。

设置保存在应用自己的偏好里，重启后仍然保留。

### 下载管理

「设置 → 下载管理」列出手机中已有的 asmr.one / DLsite 音频、缓存的 B 站音轨、这些音频的生成字幕，以及作品下载目录中的 lrc/srt/vtt 文件。每行显示文件大小。`filesDir/subtitles` 中其他生成字幕也会列出，列表名称为音频名加 `.json`。

顶部可以按文件名、RJ 号或作品名搜索。长按进入多选，可以删除或导出；只选中一项且该项带有作品编号时，还可以打开对应作品。

删除音频时，会同时删除本地文件、已完成的下载记录和这首音频的生成字幕，作品本身仍保留在音频库中。不会删除进行中的听写，也不会删除下载目录中原有的 lrc/srt。只删除字幕行时，不会删除音频。

### 听写和翻译

听写和翻译在同一个页面配置。

#### 听写

听写支持五种接口。每个模型分别保存地址和密钥；线上模型只填 API Key，本地服务填地址和口令。切换模型后，输入框只显示该模型已保存的内容；保存和清除也只作用于当前模型。进行中的任务继续使用它自己的模型和口令。

- `whisper-1`：线上模型，只填 API Key。请求固定发往 `https://api.openai.com`，模型名 `whisper-1`，语言为日语，需要分段时间。单次请求最长等待 10 分钟。文件超过 25MB 时会先询问；确认后仍然上传，取消则记为「已中止」。
- `whisper（本地部署）`：需要填写地址和口令。地址没有 `/v1` 时，请求前会补上。请求内容与 `whisper-1` 相同，模型名仍发送 `whisper-1`。文件超过 25MB 时不再询问。服务不校验口令时，填任意非空内容即可。
- `qwen-audio-3.1-asr`：线上模型，只填 API Key。请求固定发往 `https://dashscope.aliyuncs.com`。无论音频多长，都会先上传到临时存储，再轮询结果；超过 1GB 不上传。
- `Qwen3-ASR`：需要填写地址和口令。应用先读取服务上的模型名，再请求 `/v1/audio/transcriptions`，语言为日语。返回分段时间时按段生成字幕；只返回整段文字时，写成覆盖整首时长的一条；没有时长也没有分段时间时，记为「没有分段时间」。
- `本机任务接口`：需要填写地址和口令。按 [docs/whisper-api.md](docs/whisper-api.md) 提交到 `POST /jobs`，再查询进度和字幕。

没有保存过模型时，地址路径去掉末尾斜杠后以 `/v1` 结尾且域名为 `api.openai.com` 的，视为 `whisper-1`；其他以 `/v1` 结尾的地址视为 `whisper（本地部署）`；其余视为本机任务接口。保存听写地址时不会自动补 `/v1`。

听写地址是局域网、本机或 `.local` 时，Android 会询问是否允许访问本地网络，需要允许。公网地址不会询问。

#### 翻译

翻译只支持通用大模型，可选「千问AI平台」或「DeepSeek」。两个平台的请求地址固定，不需要填写：

- 千问AI平台：`https://maas.qianwenaiapi.com/compatible-mode/v1/chat/completions`。模型名不填时使用 `qwen3.8-flash`。
- DeepSeek：`https://api.deepseek.com/chat/completions`。模型名不填时使用 `deepseek-flash`。

口令必须填写。两个平台的口令和模型名分别保存。

深度思考默认关闭。打开后可以选择思考强度：千问AI平台有低、中、高三档，DeepSeek 有高、最高两档。关闭时单次请求最长等待 3 分钟，打开后最长等待 10 分钟。

日文字幕按每批最多 40 句发送，返回的每一行必须是「编号|译文」。任意一批格式不正确，整次翻译失败，已完成的批次不会保存。

「翻译后自动润色」默认关闭。打开后，翻译完成会再请求模型润色一遍；润色失败时保留刚译好的译文。查看中文字幕时，也可以手动点「润色」。手动润色不会出现在下载列表中；离开正在播放页不会中断已经开始的润色。润色失败同样保留原译文。

### 清理缓存

「设置 → 清理缓存」显示封面图片等临时缓存的占用，并允许设置上限。默认上限为 200MB，可选 100MB、200MB、500MB、1GB、2GB。

缓存占用超过上限后，应用会按文件修改时间从早到晚删除，直到回到上限以内。点「清理缓存」会立即清空这份临时缓存。

下载的音频、B 站缓存音轨和字幕不在清理范围内；需要删除时，请到「下载管理」处理。

| 位置 | 内容 |
| --- | --- |
| `ui/components` | 顶栏、多选栏、来源标签、空状态、封面 |

## 编译

想自己跑起来，用 Android Studio 打开工程即可。命令行编译当前代码：

```sh
export GRADLE_USER_HOME="$HOME/.gradle"
./gradlew :app:compileDebugKotlin --no-configuration-cache
```

主要版本：Kotlin 2.2.10，Android Gradle 插件 9.4.1，compileSdk 37，minSdk 24，targetSdk 37。界面用 Jetpack Compose，本地库用 Room 2.8.5，播放用 Media3 1.10.1，网络用 OkHttp 4.12.0。依赖仓库先走阿里云镜像。

本机若是 JDK 25，Kotlin 会退回到 24 来编译，这是提示，不是失败。
