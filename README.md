# 音频播放器

仓库包含两个客户端：

- [Android](Android/README.md)：Android 7.0（API 24）及以上的手机播放器，界面用 Jetpack Compose。安装包在 [Releases](https://github.com/nanahoshi114/AudioPlayer/releases/latest) 下载。
- [DesktopDemo](DesktopDemo/)：Windows 桌面播放器（WPF，.NET 8）。

Android 工程的编译方式和功能说明见 [Android/README.md](Android/README.md)，接口资料在 [Android/docs](Android/docs/)。
