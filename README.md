# 音频播放器

Android 上的音频播放器。可以听本机文件，也可以听 B 站视频里的音轨、[asmr.one](https://asmr.one/) 上的音声，以及自己在 DLsite 已经买过的作品。应用名是「音频播放器」，包名 `com.nanahoshi.audioplayer`。

主要能做这些事：

- **音频库**：用文件夹收纳本地文件、B 站音轨和在线作品，可以搜索、筛选、多选。
- **在线搜索**：热门来自 asmr.one；自己搜时，asmr.one 和 DLsite 一起查，同一部作品合成一张卡片。
- **已购播放**：登录 DLsite 后，可以听、可以下载自己买过的音频。
- **播放**：后台继续播，能排当前队列、定时关闭，本地、B 站和 asmr.one 还能对上字幕。
- **下载**：在线音频可以单首下、多选一起下，或把整个作品夹缓存到手机。

播放在线内容时，没点「保存」就不会写进音频库。密码只用来换登录凭证，不会存下来。没有购买的作品不会去编一个下载地址，被打乱的图片也不会拼回去。

## 界面

底部四个分页：音频库、播放列表、在线搜索、我的。这四页上方有标题栏，右上角是下载列表，底下是正在播放的小条。点进作品详情、已购买列表、收藏夹、正在播放、下载、文件预览时，底栏会让开，变成单独一页。

音频库和在线搜索顶部的搜索、筛选，手指往上滑会收起来，往下滑再出来。排序、导入，以及多选时的操作条，一直留在上面。

## 音频库

库是一层一层的文件夹。本地文件、B 站音轨、在线作品都可以放在里面。

右上角「+」可以：

- 新建文件夹
- 选择文件导入
- 选择文件夹导入（可以保留原来的文件夹结构）
- 输入 BV 号或视频链接，只导入、不立刻播放
- 输入 RJ 号，导入 asmr.one 上的整部作品

顶部可以按名称或按加入时间排序，也可以在「全部 / B站 / asmr.one / 本地」之间筛选。

- 「B站」只列出 B 站音轨，不再显示文件夹。
- 「asmr.one」只列出带作品编号的在线作品文件夹，包含从 DLsite 保存进来的作品，不把里面的单首拆开。
- 「本地」仍按文件夹浏览。在线作品文件夹会被藏起来，文件夹里也只留本机音频。如果当时正站在某个在线作品里面，会先退到最近的普通文件夹。
- 搜索时也会套用当前筛选。搜纯数字时，会额外对上作品编号。

点进已保存的在线作品，还留在音频库里：上面是封面、标题、社团、声优、发售、标签，旁边有「详情页」。图库和试听不在这一页。子文件夹也继续在库里往下走。空的已购作品文件夹会再去读一次文件；读取时提示「正在读取文件…」，两边都没有文件时提示「没有读到这个作品的文件」。

长按进入多选。操作有：下一个播放、加到末尾、加入播放列表、下载、移除。选中的那一项会把完整名字换行显示出来，没选中的仍只显示一行。点进子文件夹从这一层开头看；返回时，上一层还停在刚才滑到的位置。每一层各自记着。从上一层再次点进同一个文件夹，会重新从开头看。

单条「更多」里，在线音频可以单独下载；带作品编号的文件夹可以「缓存到本地」。图片和文本可以打开预览。字幕文件不单列出来，对应音频上会标「有字幕」。

## 播放

播放走系统前台服务，通知栏可以接着控。正在播放页有封面、进度、上一首 / 暂停 / 下一首，以及定时关闭。到时会停，并弹出提示。

当前播放队列可以拖动排序、删一首或清空。队列里可以放还没保存进库的在线音频，关掉应用前这段队列还在。

字幕只接已经在库里的音频：

- 本地文件：找同一层里同名的字幕。
- asmr.one：找同一文件夹里同名的文本。
- B 站：用视频自己的字幕。
- DLsite 音轨，以及没保存进库、只是临时点开的音频，不显示字幕。

## 播放列表

可以新建、改名、删除。列表里的曲目能拖动排序。整张列表可以替换当前播放，或接到当前队列末尾。也可以从音频库把选中的音频加进来。

## 在线搜索

没填搜索词时，热门列表只来自 asmr.one。

输入关键词后，asmr.one 和 DLsite 同时查，再按 RJ 号合并。两边都有时，卡片用 asmr.one 的声优、标签和发售信息，并标上「DLsite 也有」。只有 DLsite 有的，用商店搜索结果里的标题、社团和封面。

筛选：

- 标签只能从固定列表里点，列表项是数字编号加中文名。编号前面的 0 要留着，例如 `073`。输入框只用来在这份列表里过滤，不会变成普通关键词。已经加过的编号不再出现。多个标签是「同时满足」。
- 声优、社团仍是自己输入的文字。
- 「全年龄」只查 DLsite 的全年龄分区。
- 「有字幕」只影响 asmr.one。
- 排序有发售日、最新收录、销量、价格、评分、评价数、RJ 号和随机。DLsite 对得上的用对应排序，对不上的用它的默认趋势。

作品详情是一整页往下滚，返回和「保存」固定在顶上。

- **图库**：来自商品页和商品信息里的主图、样品图。手机开着流量时先不加载，要点「预览」；连着 Wi-Fi 时直接显示。
- **内容试听**：从 chobit 的试听页读取。没有试听时显示「没有试听」。压缩包形式的试听不能播。
- **文件**：标题会写明来自 asmr.one 还是 DLSite Play。asmr.one 上找不到这部作品、并且对方明确说没有收录时，文件区显示「asmr.one未收录」，图库和试听仍保留。别的连接失败只提示错误，不当成「未收录」。

已登录并且这部是买过的，资料上会标「已购买内容」，文件可以在「DLSite Play」和「asmr.one」之间换。默认先看 Play。两边文件名一样也当成两首，下载状态分开记。

点单首只播放，不自动保存。点「保存」才把整部作品放进音频库。

Play 里会跳过打乱过的图片、没有优化音轨的文件、切片视频和电子书页。试听地址不会带上 DLsite 的登录凭证。

## 我的

DLsite 可以用账号密码登录，也可以粘贴整段 Cookie（网站发给浏览器的登录字条）。登录后不会自动列出已购作品，要点「查看已购买作品」才打开单独一页；点其中一部会去在线作品页。

B 站登录放在同一页，可以填 SESSDATA，或整段 Cookie。输入时遮住，可以保存或清除。点「查看收藏夹」打开单独一页，选中视频后「导入到音频库」，放进库的最外层。

## 下载

这些地方可以下载 asmr.one 或已购买的 DLsite 音频：

- 音频库里单首的「更多」
- 长按多选后的「下载」（选中的文件夹会带上里面的音频）
- 在线作品文件夹的「缓存到本地」
- 作品详情里每一首旁边的下载

已经在本机、或正在下载的会跳过。本机文件和 B 站音轨不会进这个队列。下完的文件放在应用自己的目录里，之后播放走本地文件。下载页能看进度，失败可重试，下完的可以点开播放。

DLsite 已购文件每次播放或下载前，会先换一个带时效的地址和配套凭证。地址过期或被拒绝时会再换一次。

## 代码怎么分

| 位置 | 做什么 |
| --- | --- |
| `ui/library` | 音频库、收藏夹导入、图片和文本预览 |
| `ui/playlist` | 播放列表 |
| `ui/player` | 正在播放、底部小条 |
| `ui/asmr` | 在线搜索、作品详情、我的、已购买列表 |
| `ui/download` | 下载队列 |
| `playback` | 播放服务、在线音频读取、字幕 |
| `bilibili` | B 站视频、收藏夹、字幕 |
| `asmr` | asmr.one 作品、搜索、音轨地址 |
| `dlsite` | 商店搜索、商品页、登录、已购 Play 文件、标签表 |
| `data` | 音频库、下载、登录信息的保存 |
| `data/db` | 本地数据库，当前是第 6 版 |

本地库存这些东西：文件夹、音轨、作品里的图片和文本、下载任务、播放列表、当前播放队列、上次播放到哪。在线作品的同一首，用「来源 + 作品 + 文件」区分，避免 asmr.one 和 DLsite 撞成同一条。

接口对照记在：

- [docs/asmr-one-api.md](docs/asmr-one-api.md)
- [docs/dlsite-api.md](docs/dlsite-api.md)

`docs/dlsite-api.md` 开头有一句旧说明，写播放器还不直接请求 DLsite。现在搜索、登录和已购播放已经接上了，行为以这份 README 和代码为准。

## 编译

用 Android Studio 打开工程即可。命令行编译当前代码：

```sh
export GRADLE_USER_HOME="$HOME/.gradle"
./gradlew :app:compileDebugKotlin --no-configuration-cache
```

主要版本：Kotlin 2.2.10，Android Gradle 插件 9.4.1，compileSdk 37，minSdk 24，targetSdk 37。界面用 Jetpack Compose，本地库用 Room 2.8.5，播放用 Media3 1.10.1，网络用 OkHttp 4.12.0。依赖仓库先走阿里云镜像。

本机若是 JDK 25，Kotlin 会退回到 24 来编译，这是提示，不是失败。
